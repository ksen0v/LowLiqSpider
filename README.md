# LowLiqSpider 🕷

Скринер для скальпера: ищет на неликвидных монетах **MEXC** и **Gate** (спот) работающие алгоритмы
маркетмейкера: ершей (пинг-понг), широкий спред с наливами, иглы, всплески объёма и резкие движения цены.
Как только детектор срабатывает, монета появляется в сетке графиков (по умолчанию 3×3) вместе с причиной
алерта, уровнями для лимиток и кнопкой «Стакан ↗», которая открывает пару на бирже.

Торговли в сервисе нет: он только находит монеты, торгуете вы из своего терминала. API-ключи не нужны,
всё работает через публичные API бирж.

## Что ищем

| Детектор | Что это значит | Как определяется |
|---|---|---|
| **Ёрш / пинг-понг** | Маркетмейкер крутит объём сам в себя в коридоре: покупает по верху, продаёт по низу | В ленте сделок за окно (10 мин): баланс покупок и продаж, повтор объёмов, пары «покупка ↔ продажа одного размера», чередование сторон, сделки на нескольких уровнях цены. Коридор = средняя цена покупок тейкеров − средняя цена продаж. На графике рисуются линии «Покупать ~» и «Продавать ~» |
| **Широкий спред + наливы** | Между бидом и аском несколько процентов, и в спред регулярно наливают с обеих сторон | Спред из тикера + сделки за окно с обеих сторон |
| **Иглы / прострелы** | Алгоритм выбивает цену вверх и вниз длинными тенями | 1m-свечи с маленьким телом и длинной тенью, по умолчанию нужны иглы в обе стороны |
| **Всплеск объёма** | На монете включился алгоритм | Средний объём последних N минут во сколько-то раз выше среднего за час |
| **Резкое изменение цены** | Памп или пролив | Макс. отклонение цены за окно, включая уже откатившиеся прострелы |

Сканируются только монеты, которых **нет на ликвидных биржах**: Binance, Bybit, OKX, Bitget (спот и
фьючерсы), Coinbase, Upbit, Kraken (спот). KuCoin и HTX доступны, но по умолчанию выключены. Листинги
загружаются через публичные API раз в 6 часов и кэшируются, так что после перезапуска фильтр работает
сразу. Дополнительно монеты отсеиваются по объёму за 24ч (по умолчанию 1 000 – 3 000 000 USDT), плечевые
токены (3L/3S…), чёрный список; белый список сканируется всегда.

## Интерфейс

- **Сетка графиков** 1×1 … 4×4. Новый алерт занимает пустую ячейку или вытесняет самую старую
  незакреплённую карточку. 📌 — закрепить, ⤢ (или двойной клик по заголовку) — развернуть на весь экран,
  Esc — свернуть.
- В карточке: 1m-свечи с объёмом (переключатель 1m/5m/15m/1h на графике), маркеры алертов, линии уровней,
  лента сделок справа. Повторяющиеся объёмы в ленте подсвечены жёлтым, так пинг-понг видно глазами.
  Если на одну монету сработало несколько детекторов, у карточки несколько бейджей; клик по бейджу
  показывает его причину и уровни.
- **Лента** — история алертов; клик открывает монету в сетке.
- Фильтры по биржам и детекторам в шапке определяют, что попадает в сетку, ленту и звук.
- **+ Пара** — открыть любую пару вручную; там же видно, есть ли монета на ликвидных биржах.
- Звук для каждого детектора свой. Браузер разрешает звук только после первого клика по странице.
- Статус в шапке: сколько монет в скане, сканов в минуту, ошибки API (подробности во всплывающей подсказке).

## Настройки

Всё настраивается в интерфейсе (кнопка «Настройки») и применяется сразу, без перезапуска. Для MEXC и
Gate настройки отдельные:

- **Основное**: включить биржу, шаблон ссылки на пару, пауза между повторными алертами по одной монете.
- **Отбор монет**: котируемые валюты, диапазон объёма за 24ч, исключение ликвидных и плечевых, списки.
- **Сканирование**: частота опроса тикеров, минимальный интервал глубокого скана, число воркеров,
  лимит запросов в секунду, сколько свечей и сделок грузить, пороги «горячих» монет.
- **Детекторы**: у каждого свой выключатель и пороги.

По умолчанию для ерша на MEXC минимальный коридор 0.3% (мейкер на споте платит 0%), на Gate 0.5%.

Отдельные вкладки: ликвидные биржи (какие учитывать, спот/фьючерсы, ручной список, проверка тикера),
Telegram, интерфейс.

### Telegram

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Напишите своему боту `/start`.
3. Узнайте свой chat_id у [@userinfobot](https://t.me/userinfobot). Для группы добавьте бота в группу.
4. В настройках включите отправку, вставьте токен и chat_id, сохраните и нажмите «Отправить тестовое
   сообщение». Можно выбрать, какие детекторы слать в Telegram.

## Запуск

Нужен Python 3.11+.

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Откройте http://127.0.0.1:8000.

### Docker

```bash
docker compose up -d --build
```

Настройки и история алертов лежат в `./data/spider.db`.

### Демо-режим

Чтобы посмотреть интерфейс без доступа к биржам, запустите с `SPIDER_DEMO=1`. Вместо MEXC и Gate
подключатся синтетические рынки, где по расписанию «включаются» ёрш, спред, иглы, памп и всплеск объёма.

```bash
SPIDER_DEMO=1 uvicorn app.main:app --port 8000
```

### Переменные окружения

| Переменная | Назначение |
|---|---|
| `SPIDER_DB` | Путь к SQLite, по умолчанию `data/spider.db` |
| `SPIDER_AUTH_USER`, `SPIDER_AUTH_PASSWORD` | Логин и пароль (HTTP Basic). Обязательно задайте, если сервер доступен из интернета: в настройках хранится токен Telegram-бота |
| `SPIDER_DEMO=1` | Демо-режим |
| `SPIDER_DISABLE_SCANNER=1` | Только веб-интерфейс, без сканера (для отладки) |
| `SPIDER_LOG_LEVEL` | Уровень логов, по умолчанию `INFO` |

## Как это работает

```
            тикеры всех пар (1 запрос / 5 с)
MEXC/Gate ───────────────────────────────▶ отбор монет ──▶ «горячие» (резкое движение по тикерам)
    ▲                                         │                    │ вне очереди
    │   1m-свечи + лента сделок               ▼                    ▼
    └──────────────────────────────── глубокий скан по кругу ──▶ детекторы ──▶ алерт
                                                                           │
                         SQLite (история, пауза между алертами) ◀─────────┤
                         браузер (WebSocket) ◀─────────────────────────────┤
                         Telegram ◀────────────────────────────────────────┘
```

- Лента сделок запрашивается, только если по свечам видно хоть какой-то оборот: мёртвые монеты не
  тратят лимиты API.
- Запросы сканера и графиков в интерфейсе лимитируются отдельно, поэтому графики не ждут сканер.
- Ответ 429 от биржи обрабатывается паузой и повтором. Если в статусе растут ошибки, уменьшите
  «Лимит запросов в секунду».
- Если какая-то ликвидная биржа недоступна (например, Binance отвечает 451 из США), её счётчик в
  шапке подсветится, а фильтр продолжит работать по остальным биржам и по последнему кэшу. Такую
  биржу можно выключить в настройках.

Структура:

```
app/
  main.py            FastAPI, API, WebSocket
  scanner.py         сканер биржи: отбор монет, горячие, глубокий скан
  detectors/         ping_pong, spread, wicks, volume_spike, price_change
  exchanges/         mexc, gate (публичный REST API), demo
  liquid.py          листинги ликвидных бирж
  alerts.py          пауза между алертами, рассылка
  telegram.py        отправка в Telegram
  settings.py        модель настроек (из неё же строится форма в интерфейсе)
  storage.py         SQLite
static/              интерфейс (без сборки), lightweight-charts от TradingView
tests/
```
